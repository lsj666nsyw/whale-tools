# 鲸鱼工具箱 · 小工具集

31 个常用小工具，纯前端、浏览器本地运行，输入不上传。

线上地址：https://lsj666nsyw.github.io/whale-tools/

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 + 样式 + 31 个工具的界面 + 总览页 |
| `tools.js` | 通用组件 + 第 1～12 个工具 + 搜索过滤 |
| `tools2.js` | 第 13～24 个工具 |
| `tools3.js` | 第 25～31 个工具（新增）+ 总览页渲染 + MD5 实现 |
| `libs/` | qrcode.js、pdf-lib、xlsx、jszip |

## 页面结构

打开默认显示 **「📋 全部工具」总览页**——31 张卡片按使用频率排列，
常用的带橙色「常用」标记，点卡片直达对应工具。也可以用上方搜索框。

导航顺序同样按频率排：编码类（二维码/文本/JSON/Base64/URL/哈希/字数）在前，
低频工具（抽签/随机数/身份证）在后。

## 搜索

导航上方搜索框，支持中文名、英文、拼音、别名：

- 中文：`二维码`、`身份证`、`假文`
- 英文：`base64`、`hash`、`csv`、`md5`
- 别名：`改大小`、`加密`、`换算`、`占位`

关键词维护在每个 nav 按钮的 `data-k` 属性里。新增工具时必须同时补 `data-k`，
否则搜索不到（`test_smoke.js` 有一条断言专门守这个）。

## 测试

```bash
node test_smoke.js      # 23 项：页面加载、导航切换、图片压缩、搜索、9 个工具抽查
node test_search.js     # 23 项：搜索过滤专项（含 Esc、自动切换）
node test_new.js        # 43 项：8 个新工具的数值断言 + 总览页 + 回归
node _calib_search.js   # 反向校准：破坏样本必须 FAIL
```

测试用 jsdom 内联脚本跑，不走网络（HTTP 加载多脚本有资源竞态，
同一条命令反复跑结果不稳定）。依赖从 `../webapp/node_modules` 解析。

### 新工具的测试要点

`test_new.js` 全部用**数值断言**，不靠"看起来对"：

- 计算器：`1+2*3=7`、`2^10=1024`、`0.1+0.2=0.3`（无浮点误差）、
  `sqrt(144)=12`、`max(3,9,2)=9`、危险输入被拒
- 文本对比：LCS 差异统计（相同/仅A/仅B 行数）+ 增删标记
- JSON⇄CSV：双向转换、含逗号值转义、数字类型还原、非法输入报错
- MD5：`MD5("abc")`、`MD5("")` 对照标准值
- 关键字：命中计数、`<mark>` 数量、正则模式

## 已知限制

- `URL.createObjectURL` 在 jsdom 未实现，图片压缩的预览/下载在测试环境不可用，
  真实浏览器正常。
- 简繁转换是常用字对照表，非全字库。
- MD5 不适用于密码等安全场景（页面已标注）。
