# 鲸鱼工具箱

24 个常用小工具合集，纯前端、浏览器本地运行，输入不上传。

线上地址：https://lsj666nsyw.github.io/whale-tools/

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 + 样式（内联 CSS）+ 24 个工具的界面 |
| `tools.js` | 通用组件 + 第 1～12 个工具 |
| `tools2.js` | 第 13～24 个工具 |
| `libs/` | qrcode.js、pdf-lib、xlsx、jszip |

注意：本仓库**不用** `core.js` / `app.js` / `createToolbox()`——那是 `whale-batch`
仓库（图片/PDF/表格三件套批量处理）的结构。两个仓库是不同产品。

## 工具列表

| 分类 | 工具 |
|---|---|
| 编码 | 二维码、Base64、URL、哈希、摩斯 |
| 文本 | 文本处理、字数统计、简繁转换、代码格式 |
| 数值 | 单位换算、百分比、随机数、比例换算 |
| 时间 | 时间戳、日期计算、生肖 |
| 生成 | 密码、抽签、命名风格 |
| 数据 | JSON 格式化 |
| 媒体 | 图片压缩（单张，限最大边长） |
| 校验 | 身份证校验、内容类型校验 |

## 工具搜索

24 个工具横排，手机上要滚很久。导航上方有搜索框，支持：

- 中文名（`二维码`、`身份证`）
- 英文/拼音（`base64`、`hash`）
- 别名关键词（`改大小`、`加密`、`换算`）

关键词维护在每个 nav 按钮的 `data-k` 属性里。过滤后如果当前选中的工具被藏掉，
会自动切到第一个可见工具；`Esc` 清空搜索。

## 测试

```bash
node test_smoke.js      # 23 项：页面加载、导航切换、图片压缩、9 个工具抽查、搜索
node test_search.js     # 18 项：搜索过滤专项
node _calib_search.js   # 反向校准：破坏样本必须 FAIL
```

测试用 jsdom 内联脚本跑，不走网络（通过 HTTP 加载多个脚本有资源竞态，
同一条命令反复跑结果不稳定）。依赖从 `../webapp/node_modules` 解析。

## 已知环境限制

`URL.createObjectURL` 在 jsdom 里未实现，图片压缩的预览/下载在测试环境不可用，
真实浏览器正常。测试只验证"有处理反馈"，不断言下载链接一定出现。
