批量改尺寸

按长边、固定尺寸、百分比缩放。等比缩放+补白边，不变形不拉伸。内置淘宝 800×800、京东、小红书等常用规格。

🗜️

批量压缩

可指定「压到 200KB 以下」，程序自动调质量逼近目标。不会瞎压——优先保证画质够用的前提下最小。

🔲

补白边成正方形

做电商主图刚需。非正方形的图自动补白边成正方形，完整保留内容，不裁掉任何部分。

✂️

智能去白边 专业版

自动识别并裁掉四周的纯色边。白边、黑边、任意纯色边都行。强度可调，不会误伤内容。

🪄

批量抠图 专业版

纯色背景（白底/蓝布/绿幕）一键变透明，输出 PNG。边缘自动柔化，比硬边自然。

🖼️

加边框 专业版

纯色描边，5 种预设色。商品图加一圈细边框，在列表里更精神、更整齐。

9 个位置，透明度和字号可调。带半透明描边，浅色图上也能看清。支持中文。

常见问题

会覆盖我原来的图片吗？

不会。原图完全不动，处理结果输出到你指定的文件夹。如果输出文件夹里有同名文件，会自动加 _1、_2 后缀，绝不覆盖。

图片会被传到网上吗？

不会。这是纯本地程序，不联网、不上传任何东西。断网也能正常用。

需要装 Python 或者其他软件吗？

不需要。下载的是一个 exe 文件，双击就能运行。Python 运行时已经打包在里面了（所以文件有 30MB）。

Windows 提示"未知发布者"怎么办？

点「更多信息」→「仍要运行」即可。这是因为没有购买代码签名证书（一年要几千块），不影响使用。

抠图能抠复杂背景吗？

不能。这个工具只适合纯色背景（白底、蓝布、绿幕）。复杂背景请用专业抠图软件或在线 AI 抠图服务。

支持哪些图片格式？

输入支持 jpg / jpeg / png / webp / bmp / tif / tiff / gif。输出支持 jpg / png / webp。

能处理 RAW 格式（CR2 / NEF）吗？

不能。只支持常见的网络格式。

买了以后能换电脑用吗？

能。不限设备，拷过去就能用。

用不了能退吗？

能。如果在你机器上跑不起来、或者功能达不到你的需求，说明情况全额退。
